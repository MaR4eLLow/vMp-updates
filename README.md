# vMp - vk Music player (Windows x64 only)
### Desktop'ый музыкальный плеер на основе ВКонтакте.
- Не отправляет телеметрию.
- Связан только с сервером ВКонтакте.
- Приложение не передаёт данные на сторонние сервисы, общается исключительно с GitHub (Для обновлений) и vk.ru. Работает на основе перехвата сессии, эмулирует реальное использование браузера.

> Данный проект создавался изначально в личных целях, для удобного прослушивания музыки из ВК во время игр. Так как браузер кушал сильно много оперативной памяти.

### Установка и запуск 
vMp-x.x.x-setup.exe — обычная установка, поддерживает автообновления.

vMp-x.x.x-portable.exe — без установки, обновляется вручную.

#### Возможности:
- Прослушивание музыки (Логично, да?)
- Поиск треков
- Настройка эквалайзера
- Стилизация плеера под себя

#### Планируется:
- Добавление своих VST плагинов
- Прослушивание треков друзей
- Добавление треков в свою музыку
- Создание плейлистов
- Полное кэширование и скачивание треков на компьютер
